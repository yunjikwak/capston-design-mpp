## 📌 프로젝트 소개

SquirFit은 2025년 컴퓨터·인공지능공학부 캡스톤디자인 경진대회를 위해 개발된 **하이브리드 자세 교정 서비스**입니다.

사용자는 스쿼트 동작 시 전신의 관절 정렬과 발바닥 하중 분포를 실시간으로 분석받아, 부상 위험을 줄이고 운동 효과를 극대화할 수 있습니다.

단일 모달리티의 한계를 극복하기 위해 영상 데이터(Google MediaPipe)와 임베디드 센서 데이터(스마트 인솔)를 결합했습니다. 연속적인 스쿼트 동작을 4단계 상태 머신으로 세분화하고, 신뢰도 기반 노이즈 필터링을 적용하여 실시간 피드백의 정확도와 안정성을 확보했습니다.

FastAPI를 활용해 저지연 WebSocket 스트리밍 통신과 AI 분석 모델 서빙 아키텍처를 통합 구축하였으며, iOS 클라이언트 및 IoT 센서와의 실시간 연동을 통해 소프트웨어(비전 AI)와 하드웨어(IoT)가 융합된 정밀한 피트니스 코칭을 제공하는 것을 목표로 합니다.

## 🏗️ 시스템 아키텍처

전체 시스템은 4가지 주요 컴포넌트로 구성됩니다.

- **iOS 애플리케이션**: 사용자와 상호작용하는 엔드포인트. 시각 및 음성 피드백을 실시간으로 제공하며 실제 앱스토어에 배포됨
- **Spring Boot 서버**: AI 서버의 자세 데이터와 IoT 서버의 압력 데이터를 통합하여 오차를 비교 분석하고 최종 교정 피드백 생성. REST API를 통해 모바일 앱과 연동, 데이터 저장 및 사용자 인증 담당
- **AI 서버**: Google MediaPipe 프레임워크 기반으로 입력된 실시간 영상의 자세를 분석
- **IoT 서버**: 스마트 인솔 하드웨어(ESP32)에서 수집된 족저압 데이터를 실시간 전송받아 Spring Boot 서버로 전달



## ✨ 주요 기능

- 카메라 기반 주요 관절 좌표 추적 및 실시간 자세 분석
- 스마트 인솔을 활용한 발바닥 부위별 압력 분포 출력
- 10초마다 자세에 대한 음성 및 시각적 피드백 제공
- 운동 시 자동 횟수/세트 카운팅
- 운동 완료 후 결과 데이터 확인



## 🤖 AI 기반 영상 분석 (담당 구현 파트)

### 1. 관절 좌표 및 각도 산출

카메라를 통해 측면 전신 영상을 입력받아 MediaPipe로 어깨, 엉덩이, 무릎, 발목 등 주요 관절 지점의 2D 좌표를 추출합니다. 추출된 좌표 벡터의 내적 및 크기를 통해 주요 관절의 각도를 실시간으로 추적합니다.

### 2. 방향 자동 인식

visibility 합을 이용한 좌/우 측면 자동 선택 로직으로 사용자가 좌측면인지 우측면을 향하고 있는지 자동으로 구분합니다.

### 3. 4단계 상태 머신 (State Machine)

연속적인 스쿼트 동작을 아래 네 단계로 자동 분류합니다.

| 단계     | 설명                                                           |
| -------- | -------------------------------------------------------------- |
| `Start`  | 신체 정보를 기준값으로 저장하고 허리와 무릎이 펴졌는지 확인    |
| `Sit`    | 엉덩이 하강 및 허리/무릎 굽힘 정도를 분석하여 자세 유지 확인   |
| `Rising` | 무릎과 등의 정렬 상태를 확인하여 올바른 기립 여부 판단         |
| `Stand`  | 무릎이 펴지고 기준값으로 돌아오면 횟수를 1회 증가(자동 카운팅) |

### 4. 자세 품질 평가 및 피드백
- 무릎/등/발목 관련 체크 값 반환 구조
- 평균 점수 및 등급(grade) 산출 로직
- 반복 완료 시 상세 결과(`score`, `breakdown`, `recent`) 반환 가능

### 4. 실시간 통신 및 서빙

- FastAPI로 Client와의 실시간 양방향 통신을 위한 WebSocket 서버 구축
- AI 모델 서빙 API 구축

### 5. 클라우드 인프라

- **컨테이너화**: Docker를 사용하여 서버 애플리케이션 가상화
- **Azure Container Apps 배포**: 서버리스 컨테이너 환경에 애플리케이션 배포
- **CI/CD 파이프라인**: GitHub Actions와 연동하여 코드 변경 시 빌드, 테스트, 컨테이너 이미지 푸시 및 배포 자동화

## 🔩 하드웨어 (스마트 인솔) 구성

- ESP32 DevKitC WROOM-32U 보드 1개 + 각 발당 6개의 FSR400 압력 센서 (총 12개)
- 센서 배치: 전족부(3개), 중족부(1개), 후족부(2개) — 스쿼트 시 압력이 집중되는 부위 전략적 배치
- 브레드보드 대신 만능기판에 직접 납땜하여 연결 불량 방지 및 내구성 향상
- ESP32가 족저압을 측정하여 압력 비율을 계산, Wi-Fi를 통해 1초마다 Spring Boot 서버로 전송

## 🔀 하이브리드 피드백 시스템

- **멀티모달 데이터 통합**: 비전 데이터와 족저압 센서 데이터를 결합하여 전후 무게중심 이동, 좌우 발 비대칭 여부 등을 정밀 분석
- **다중 피드백**: 올바른 자세를 벗어날 경우 시각적 오류 표시 + 음성/텍스트 안내 즉각 제공
- **접근성**: 스마트 인솔이 없는 환경에서도 영상 데이터만으로 단독 자세 분석 가능
